# Post-deadline audit and reporting supplement

This supplement accompanies manuscript release v0.2.2. It preserves the
120-run scientific results and the original three weekly prefix probes.
The two new complete-May replays test one additional, predeclared calendar
cutoff after actual seven-day deadline re-scoring has occurred.

The May 20 07:00 UTC cutoff preserves 21,683 arrivals and leaves a 14,232-record
suffix. Both output prefixes contain the same 21,328 complete events: 20,961
arrival, 229 claim, and 138 deadline outputs. All 138 own deadlines precede
month-end drain, at exactly seven days. All 98 deadline scorer calls at 96
equal-time deadline/arrival timestamps occur before arrival processing.
This is finite fixed-stream audit coverage. Full logs remain local; their
hashes, aggregate counts and comparison results are recorded here.

## Reproduce the supplement

The July contrasts are generated by the existing aggregate summary command in
[ARTIFACT.md](../../ARTIFACT.md). Select July/gbt/f1 rows with the two arm pairs
`invisible_gate5,arrival` and `gate5,invisible_gate5`. The released source-count
CSV makes the paired five-fit computation explicit.

The resource table needs only public aggregates:

```text
python -m analysis.round2_resources --run-dir reproductions/revision_v2 --code-root . --out-dir build/round2_resources
```

Add `--verify-events` when using a trusted local completed run with its private
event files. It recomputes waiting intervals from event timestamps. The published
resource report records that optional local check; an aggregate-only rerun does
not reproduce the omitted event logs.

For a new post-deadline replay, first follow [REPRODUCE.md](../../docs/REPRODUCE.md)
to create the local May cache/model, the May Gate seed13 event log, calibration
selection and original prefix-audit report. Use 64-bit Python and a fresh output
directory, then run from the repository root:

```text
python -m analysis.round2_prefix_audit --source-run /path/to/completed-run --output-dir /path/to/new-audit-run --freeze
python -m analysis.round2_prefix_audit --source-run /path/to/completed-run --output-dir /path/to/new-audit-run --run
```

`--freeze` refuses to replace an existing protocol. `--run` verifies frozen
input and source hashes before replay. The original observed timings are single
local-worker measurements; resource Table 6 instead reports the original
six-worker trace-enabled suite. These measurement configurations are distinct.
